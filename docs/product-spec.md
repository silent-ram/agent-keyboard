# 打字间产品规格

版本：1.3
日期：2026-11-22

## 1. 产品定义

打字间是一个以 Android 输入法为入口的个人资料问答工具：

1. 用户在任意输入框旁打开 AI 面板；
2. 用对话描述问题或任务；
3. Agent 按问题检索用户配置的远程资料库，也可查询公开信息；
4. 把命中片段交给用户选择的模型服务商生成答案；
5. 展示带来源的答案；
6. 用户按需将结果写入当前输入框，或选择文字复制。

MCP 是默认无连接的可选扩展，只使用用户启用的服务。产品不做手机自动化平台。

## 2. MVP 范围

### 2.1 输入法

- 作为系统输入法正常打字；
- 工具栏提供一个 AI 入口；
- AI 面板在输入法窗口内打开；
- 面板输入使用同一个输入法；
- 面板关闭后回到键盘；
- 不因 AI 初始化失败影响普通打字。

### 2.2 AI 面板

面板是所有 AI 能力的统一入口，不拆成多个独立功能页。用户可以直接描述：

- 资料问答；
- 内容整理；
- 语言转换；
- 回复生成；
- 继续追问；
- 对当前输入内容进行处理。

面板结构：

| 区域 | 内容 |
|---|---|
| 导航 | 当前对话、历史和关闭；模型管理留在面板内 |
| 消息流 | 用户消息、模型回答、检索来源、运行状态、错误 |
| 结果区 | 正文、引用、插入或替换；长按可选中文字 |
| 输入区 | 继续描述、补充限制、停止或发送 |

对话和引用不展示服务配置、资料库名称或 ID。用户说明和记忆可手动编辑，Agent 建议需要用户确认后才保存。

### 2.3 结果交付

结果交付是 AI 面板的统一能力：

- 插入当前光标；
- 替换当前选区；
- 选择文字复制；
- 继续追问。

交付前显示目标和动作。编辑器切换、密码框、上下文变化时，结果必须失效或要求重新确认。

### 2.4 远程资料库

- 支持智谱、Dify、RAGFlow。文档由用户在服务端管理；App 只选择已有资料库并检索。
- 解析、切片、向量化和索引由服务端处理。App 不保留本地检索后端，也不做故障回退。
- 每次资料库检索单独授权。命中片段可交给当前回答模型。
- 同一会话可以结合公网搜索与已有 MCP 工具。资料命中不改变外部工具原有授权，也不额外拦截资料原文。

### 2.5 服务商与配置

- 资料库、回答模型和搜索分别配置，凭据加密保存。各服务的费用以用户选择的服务为准。
- 配置可通过 `.akcfg` 迁移。配置文件包含凭据，持有文件的人可在兼容设备恢复，不应公开分享。

### 2.6 文件处理

文档导入和维护由用户在服务端完成。Android App 不扫描本机资料，不创建资料库，也不上传或删除远端文档。系统文件选择器仅用于用户主动发起的配置迁移。

### 2.7 任务记录

MVP 只需要轻量任务状态：

- 等待；
- 运行；
- 等待用户确认；
- 成功；
- 失败；
- 已取消。

任务历史显示：

- 用户问题；
- 使用的文档；
- 结果摘要；
- 来源；
- 错误原因；
- 创建时间。

不在 MVP 建立通用后台 Agent 平台。

## 3. 非目标

- 悬浮操作面板；
- 无障碍读屏；
- 设备点击、滑动和自动化；
- 通知读取；
- 语音和图片理解；
- 全设备文件扫描；
- 团队同步；
- 默认读取所有宿主文本；
- 默认上传全部键盘输入。

这些能力不是永久否定，而是必须等 MVP 验证真实使用价值后再单独立项。

## 4. 数据边界

| 数据 | 默认行为 |
|---|---|
| 普通键盘输入 | 只交给当前输入框 |
| 面板问题 | 用户点击发送后才发给配置的模型 |
| 资料库文档 | 用户在提供方后台管理，App 不上传本机文档 |
| 资料库查询 | 用户主动问答触发，逐次确认后发送给已选服务并记录 |
| 检索片段 | 命中后随本次主动问答发送给当前选择的模型 |
| 公网搜索和 MCP 参数 | 走各工具原有授权规则，参数中带入的内容可能由对应服务接收 |
| 密码框内容 | 不读取、不发送、不写日志 |
| API Key | Keystore 加密，不进日志和数据库明文 |

## 5. MVP 完成标准

- 真机可以正常使用键盘；
- 从键盘打开 AI 面板，不跳转其他 App；
- 选择服务端已建立并导入文档的资料库，能够检索；
- 回答带来源；
- 结果可以插入、替换或复制；
- 关闭面板后普通打字不受影响；
- 模型、资料库检索、联网搜索失败都有明确错误；
- 任务历史可查看、删除，继续会话后仍按真实消息顺序恢复上下文；
- 自动化测试和真机验收通过。
