# 第三方来源与许可

Agent Keyboard 产品由 `silent-ram` 维护。

- Android 键盘基座来自 Fcitx5 for Android，原始版权归其贡献者。修改版源码维护在 `silent-ram/agent-keyboard-fcitx5-android`。上游源码的版权标注与许可证随子模块保留，APK 内包含 `LICENSE-Fcitx5-Android.txt`。上游许可证为 LGPL-2.1-or-later，具体条款见 [`third_party/fcitx5-android/LICENSE`](../../third_party/fcitx5-android/LICENSE)。
- Fcitx5、LibIME 和其他依赖的原始上游地址与锁定版本用于源码追溯。各依赖的源码和许可证保存在相应的子模块内。
- 词典、模型数据及其许可见 [第三方数据清单](third-party-data-inventory.md)。
