# 打字间隐私说明

打字间由 silent-ram 维护。日常输入和 AI 面板使用不同的输入路径。普通打字在设备上处理，密码字段会停用 AI 面板。

主动发送 AI 问题时，App 使用你配置的模型服务。当前对话及你授权随请求发送的用户说明和相关记忆可能参与回答。资料库检索默认直接执行，不逐次确认；查询发送给当前选定的服务，命中的文档片段可发送给回答模型。

公网搜索同样默认直接执行，不逐次询问，并可与资料库检索、已启用的 MCP 工具在同一会话中使用。是否查到资料不改变其余工具的授权设置，MCP 工具仍按原有规则询问。检索词或搜索词逐字带有你输入框、剪贴板、用户说明或记忆中的原文时，仍会当场确认。Agent 默认用公开关键词搜索，但 App 不再按资料原文拦截；工具参数中的资料内容可能发给对应服务。活动记录不保存这些参数。

App 在本地保存配置、对话、记忆和活动记录。API Key 使用 Android Keystore 管理的密钥加密保存。配置导出由你手动执行，生成的 .akcfg 文件包含 API Key，持有文件的人可以在兼容设备上恢复和使用它们。

回答失败时，错误卡会显示一行诊断信息（错误分类、状态码和耗时），可以复制；Agent 配置页的「运行诊断」保留最近 20 次运行的结果与用量。这些只包含分类和计数，不含问题、回答或工具参数，且只留在运行内存中，不写入文件。

应用内的「最近活动」可查看已有调用记录。项目反馈请使用 silent-ram/agent-keyboard 的 Issues，提交前请移除 API Key、对话原文和个人资料。
