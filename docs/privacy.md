# 打字间隐私说明

打字间由 silent-ram 维护。日常输入和 AI 面板使用不同的输入路径。普通打字在设备上处理，密码字段会停用 AI 面板。

主动发送 AI 问题时，App 使用你配置的模型服务。当前对话及你授权随请求发送的用户说明和相关记忆可能参与回答。每次资料库检索都需确认，查询发送给当前选定的服务，命中的文档片段可发送给回答模型。

公网搜索和已启用的 MCP 工具可以与资料库检索在同一会话中使用。是否查到资料不改变这些工具的授权设置；选择「总是允许」后，符合现有授权规则的请求不会再询问。Agent 默认用公开关键词搜索，但 App 不再按资料原文拦截；工具参数中的资料内容可能发给对应服务。活动记录不保存这些参数。

App 在本地保存配置、对话、记忆和活动记录。API Key 使用 Android Keystore 管理的密钥加密保存。配置导出由你手动执行，生成的 .akcfg 文件包含 API Key，持有文件的人可以在兼容设备上恢复和使用它们。

应用内的「最近活动」可查看已有调用记录。项目反馈请使用 silent-ram/agent-keyboard 的 Issues，提交前请移除 API Key、对话原文和个人资料。
